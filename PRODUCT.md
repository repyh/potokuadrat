# Product

<!-- impeccable:product-schema 1 -->

## Platform

web

## Users

- Event organizers self-host an installation to present their organizer profile and public event documentation to clients.
- Clients and other visitors preview the organizer profile and browse publicly available documentation.

## Product Purpose

Potokuadrat gives event organizers a self-hosted web space for their profile and documentation repository, which clients can explore.

## Positioning

The organizer runs the site for their own client-facing presence and can change its event name and branding through a root configuration file. The first public landing page should connect the organizer identity with the documents available to visitors.

## Operating Context

An organizer hosts and maintains the site for an event or client engagement. Visitors arrive to preview the organizer and read public documentation. Which documents are public and what interactions require an account remain undecided.

## Capabilities and Constraints

- The root `config.json` supplies site branding. Its default event name is `Potokuadrat`.
- The site is intended to be self-hosted by event organizers.
- The landing page should foreground the organizer profile and publicly available documentation.
- Exact document types, private/client-only areas, uploads, comments, and authentication flows are undecided.

## Brand Commitments

- Default site/event name: `Potokuadrat`; organizers can change it through configuration.
- Visual inspiration references: Instagram, Pinterest, and YouTube. These are references for useful visual patterns, not a request to copy their marks or exact interfaces.

## Evidence on Hand

No organizer biography, event-specific documents, photographs, logo, testimonials, or client examples have been supplied. Do not present invented organizer details or sample documents as real content.

## Product Principles

- Make the organizer identity clear before visitors browse the repository.
- Keep public documents easy to discover and read.
- Make the self-hosted brand configurable without source edits.
- Distinguish any demo content from real organizer materials.
