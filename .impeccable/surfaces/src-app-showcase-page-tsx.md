# Component Specimen Folio

Scope: dedicated `/showcase` route presenting the reusable Potokuadrat UI component library across Core Forms & Controls, Feedback & Status (without badge/tag components), Navigation/Overlays/Data, and Event-Domain Primitives. Mode: Operate. Visitors are designers and developers inspecting live component ergonomics, state transitions (`default`, `error`, `disabled`, `loading`), and Potokuadrat's botanical ink and open-paper design system.

## Direction contract

THESIS: Potokuadrat's UI library reads as an interactive architectural specimen folio—ruled rows pairing concise documentation with live, stateful controls—refusing generic SaaS marketing cards, pill badge clutter, and decorative shadows.

OWN-WORLD: Deep botanical ink (`#183c34`), open paper surface (`#f8f8f0`), cool paper tint (`#e9eee2`), leaf accent (`#d9ef63`), quiet slate-green secondary ink (`#50675d`), and fine `1px solid` rules (`#c6d0c3`). Young Serif anchors page and chapter headings; Arial (`14px`–`15px`) with `tabular-nums` handles every interactive label, input, table cell, and metadata readout.

STORY: A builder opens `/showcase`, switches the global specimen state (`Default`, `Error`, `Disabled`, `Loading`) in the sticky specimen bar, tests every form control, overlay, and event primitive directly in place, and inspects consistent focus, validation, and responsive behavior.

FIRST VIEWPORT: Top sticky navbar with Potokuadrat brand link back to `/`, section jump links, and the live Specimen State Bar (`Default`, `Error`, `Disabled`, `Loading`), followed immediately by the `Component Specimen Folio` heading and the first ruled Core Forms & Controls chapter.

FORM: Interactive Specimen Folio (position 1, seed: none (unavailable)).

FINISH: unreviewed and undocumented is unfinished; this build ends with the finish review, the verdict, DESIGN.md, and every shipping raster carrying its provenance
